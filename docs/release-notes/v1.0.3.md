# chmate-revanced v1.0.3

書き込み欄または新規スレッド作成を開くとChMateが終了するresource回帰を修正したリリースです。

## 修正内容

- v1.0.2で、ChMate独自属性を`app:`名前空間へ戻す処理が`<include>`のフレームワーク必須属性`layout`にも適用され、実行時にレイアウト指定なしとして扱われていた問題を修正
- `<include layout="…">`は無修飾のまま維持し、通常View上の同名カスタム属性だけを`app:layout`へ戻す文脈依存の判定を追加
- 同名属性が共存するXMLを使った回帰テストを追加

## 実機検証

- 端末: AQUOS SH-R80P / Android 16
- Manager: 公式ReVanced Manager 2.6.0
- ChMate: `0.8.10.241`
- v1.0.2: 既存スレッドの鉛筆ボタンから書き込み欄を開くと、`res_2131492990`の`<include>`に`layout`がないという`InflateException`で終了することを再現
- v1.0.3: ReVanced Managerでpatch・署名・保存したAPKをデータ保持更新後、既存スレッドの書き込み欄と新規スレッド作成画面が終了せず開くことを確認

検証に使用した入手時ファイルのSHA-256（ファイル自体は配布しません）:

```text
3fd5d2eab0aa34c97462cac8c84ae30e0d67877b21a460e94917eaee4e0fa417  ChMate_0.8.10.241_APKPure.xapk
```

Release assetsはReVanced Managerが直接読み込める`patches-1.0.3.rvp`と、そのSHA-256ファイルだけです。ChMate APK、XAPK、patch済みAPKは含みません。
