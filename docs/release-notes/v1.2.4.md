# chmate-revanced v1.2.4

ChMate 0.8.10.246 devでスレッドを開くと断続的に終了する問題を修正するリリースです。

## 修正

- `ResListActivity.onStart`／`onResume`に追加されたintegrity trapを、板一覧と同じ安全なライフサイクル呼び出しへ置き換えます。
- 内部カウンタの偶奇によってnull throwまたは不正処理へ分岐し、同じスレッドでも開けたり終了したりする問題を防ぎます。
- 全メニュー回帰検査で見つかった`WebViewActivity.onStart`の同型trapにも対応し、「スレ検索」などのWeb画面を安定して開けるようにします。
- スレッドtoolbarの全操作検査で見つかった`ResEditActivity.onStart`の同型trapにも対応し、返信ダイアログを安定して開けるようにします。
- ホーム、検索、スレッド一覧を含む7 Activityを対象に、実際にthrow／divide trapを持つライフサイクルmethodだけを構造判定して修正します。

## 検証

- JDK 17のJUnit、Android Lint、RVPビルドをclean状態で完了しました。
- ChMate `0.8.10.165`、`0.8.10.179`、`0.8.10.202 dev`、`0.8.10.241`、`0.8.10.244 dev`、`0.8.10.245 dev`、`0.8.10.246 dev`へ同じRVPを適用し、全版で対象patchの成功、resource／DEX再構築、署名を確認しました。
- Pixel 10a / Android 17で同一スレッドを20回連続で開閉し、全20回で`ResListActivity`の表示に成功しました。
- ホームの全tab・12メニュー、設定14項目、追加3画面、NG編集6tab、スレッドtoolbarとmenu、返信・次スレ作成・共有dialogを開閉し、ChMate由来のクラッシュ0件を確認しました。

Release assetsには`patches-1.2.4.rvp`、そのSHA-256ファイル、更新情報の`patches.json`だけを含めます。ChMate APK、XAPK、patch済みAPKは配布しません。
