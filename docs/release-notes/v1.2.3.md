# chmate-revanced v1.2.3

Pixel 10a / Android 17で発生するReVanced Manager互換性を修正するリリースです。

## 修正

- Managerのパッチャー別プロセスでapktoolのframework保存先が書き込み不能な`/.local/share/apktool/framework`になる場合、書き込み可能なprocess cache配下の`framework`へ切り替えます。
- 同じframework保存エラーが大量にBinderへ送られ、`RemoteFailureException`でパッチ適用が終了する問題を防ぎます。

## 検証

- JDK 17のJUnit、Android Lint、RVPビルドをclean状態で完了しました。
- ChMate `0.8.10.165`、`0.8.10.179`、`0.8.10.202 dev`、`0.8.10.241`、`0.8.10.244 dev`、`0.8.10.245 dev`、`0.8.10.246 dev`へ同じRVPを適用し、全版で対象patchの成功、resource／DEX再構築、署名を確認しました。
- Pixel 10a / Android 17の公式ReVanced Manager 2.6.0で246 devのresource decode、patch、resource／DEX再構築、zipalign、署名まで完了しました。

Release assetsには`patches-1.2.3.rvp`、そのSHA-256ファイル、更新情報の`patches.json`だけを含めます。ChMate APK、XAPK、patch済みAPKは配布しません。
