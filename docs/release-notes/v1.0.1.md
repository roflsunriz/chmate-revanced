# chmate-revanced v1.0.1

ChMate 0.8.10.241 のスレッドタイトル直上に残っていた広告領域を、高さゼロへ戻す修正版です。

## 修正内容

- `toolbarContentTop` から上方向へ Constraint の連鎖をたどり、複数レイアウト間で表示状態が切り替わる同一の最上部スロットを広告枠として検出
- 難読化クラス名や数値resource IDを固定せず、誤検出を避けるため複数レイアウトでの非表示実績、`wrap_content`、親上端への制約、tag未設定をすべて要求
- 検出した枠を `0dp`・`GONE` にし、実行時の再表示もruntime collapserが再度折りたためる限定tagを付与
- v1.0.0で修正したタイトル幅、上下それぞれの更新gesture、同IDポップアップ用タップ領域はそのまま保持

## 実測検証

- 端末: Pixel 10a / Android 17 / 1080×2424px
- ChMate: `0.8.10.241`
- 修正前: タイトル直上の広告コンテナ `bounds=[0,152][1080,291]`、追加高139px
- 修正後: 同コンテナはUIツリーに存在せず、タイトルView `bounds=[0,152][1080,247]`、広告由来追加高0px
- スレッドタイトルは画面全幅、スレッド一覧の下引き更新spinner、スレッド末尾の上引き更新、ID直接タップとID行空白タップの同IDポップアップを同一候補APKで再確認
- `0.8.10.165`、`0.8.10.179`、`0.8.10.202 dev`、`0.8.10.241` の4世代すべてへ同じ `.rvp` を適用し、resource / DEX再構築、zipalign、署名に成功
