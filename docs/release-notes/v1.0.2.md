# chmate-revanced v1.0.2

ReVanced Manager上でv1.0.1のpatchがresource decode中に停止するAndroid XML parser非互換を修正したリリースです。

## 修正内容

- Androidの`DocumentBuilderFactory`が未実装の`disallow-doctype-decl` featureを必須設定していた処理を削除
- PCとAndroidの両方で利用できるAPIだけでlayout XMLを解析
- DOCTYPE／ENTITY宣言はparser実装へ依存せず解析前に拒否し、外部entity resolverも無効化したまま安全性を維持
- 悪意のあるDOCTYPE／外部entity入力を拒否する単体テストを追加

## 実機検証

- 端末: AQUOS SH-R80P / Android 16
- Manager: 公式ReVanced Manager 2.6.0
- ChMate: `0.8.10.241`
- v1.0.1: resource decode時に`ParserConfigurationException: http://apache.org/xml/features/disallow-doctype-decl`で失敗することを再現
- v1.0.2: Managerへ`.rvp`をストレージから追加し、準備2/2、patch適用2/2、保存2/2まで完走
- `classes.dex`〜`classes8.dex`、patched resourcesの再コンパイル、zipalign、署名、`result.apk`保存に成功
