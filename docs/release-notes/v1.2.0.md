# chmate-revanced v1.2.0

ChMateの更新処理を高速化し、画像掲示板と高度NGをChMate本来の画面へ統合したリリースです。

## 主な変更

- ホームの複数板・複数スレッド更新を最大4件同時に処理します。
- 4chan・ふたば・jschanの板を「掲示板設定」から登録し、ChMate標準の板一覧・スレッド一覧・レス画面で閲覧できます。
- 4chan・ふたばと登録済みjschanのURLを「URLを指定して開く」から読み込めます。
- 高度なNGルールをChMate本来のNG編集画面から開くようにしました。
- ChMate 0.8.10.246 devのCompose設定とAndroid版Managerのresource解析に対応しました。

## 検証

- JDK 17のJUnit、Android Lint、RVPビルドに成功しました。
- 同じRVPをChMate `0.8.10.165`、`0.8.10.179`、`0.8.10.202 dev`、`0.8.10.241`、`0.8.10.244 dev`、`0.8.10.245 dev`、`0.8.10.246 dev`へ公式CLI 6.0.0で適用し、全版でpatch成功、resource・DEX再構築、署名済みAPK保存を確認しました。
- 179と241はXAPKの全20／4 moduleを単一APKへ統合してから検証しました。
- `ParallelRefreshBridgeTest`で複数ワーカーの実行時間が重なること、エラー数を集約すること、板単位の分割を確認しました。
- `ImageBoardIntegrationTest`で板・スレッドURLのChMate形式への変換、短いjschanスレッドIDの安定変換、一般HTTPS URLを誤変換しないことを確認しました。
