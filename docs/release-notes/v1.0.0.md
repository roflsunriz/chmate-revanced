ChMate 向け ReVanced Patch の最初の安定版です。

## ReVanced Manager での利用

1. Release assets から `patches-1.0.0.rvp` をダウンロードします。
2. ReVanced Manager の Patches 画面で追加操作を開き、「ストレージから選択」から `.rvp` を読み込みます。
3. 自分で正当に入手した ChMate を選び、`ChMate ReVanced` patch を適用します。

ZIP への展開は不要です。ChMate APK、XAPK、patch 済み APK はこの Release に含まれません。

## 主な機能

- スレッド上部と途中の広告領域を高さゼロに変更
- 広告 SDK と Firebase 計測の初期化・通信を遮断
- ChMate 本体の設定に User-Agent の保存、復元、再起動を統合
- 難読化された複数世代の ChMate に適用できる構造ベースの patch
- ChMate独自layout属性の名前空間とenum / flag値を保持し、元のタイトル、更新gesture、ID popup操作を維持

詳細は [CHANGELOG.md](https://github.com/roflsunriz/chmate-revanced/blob/v1.0.0/CHANGELOG.md) を参照してください。

## 実測検証

- 端末: Pixel 10a / Android 17
- ChMate: `0.8.10.165`、`0.8.10.179`、`0.8.10.202 dev`、`0.8.10.241`
- `0.8.10.241` で広告由来の上部・途中の追加高がともに `0px`
- `0.8.10.241` でタイトル全幅、スレッド一覧の下引き更新、スレッド末尾の上引き更新、ID直接タップとID行空白タップの同IDポップアップを実機確認
- 全4版でpull方向・target list・layout constraintのカスタム属性が型付きbinary XMLとして保持されることを確認
- 入力した User-Agent と実際の HTTP `User-Agent` header が完全一致
- AdGuard、VPN、Private DNS、HTTP proxy を無効にした状態で Amazon Ads / Unity Ads の通信を接続前に遮断し、Firebase 計測を停止
