# chmate-revanced v1.2.1

v1.2.0のAndroid版ReVanced Manager互換性を修正するリリースです。

## 修正

- Android版ReVanced Managerが0.8.10.246 devを復号したときに残る数値resource／attr参照、framework enum、短縮color、欠落属性を正規化します。
- ChMate 0.8.10.246 devの難読化binary XMLで掲示板設定の属性名・クラス名を復元できない場合も、Compose設定画面に表示される「掲示板設定／BBSMENU」から対象を識別してパッチを継続します。
- 旧版ではXMLへ直接、新版では実行時に画像掲示板項目をChMate本来の掲示板設定へ追加します。

## 検証

- JDK 17のJUnit、Android Lint、RVPビルドをclean状態で完了しました。
- ChMate `0.8.10.165`、`0.8.10.179`、`0.8.10.202 dev`、`0.8.10.241`、`0.8.10.244 dev`、`0.8.10.245 dev`、`0.8.10.246 dev`へ同じRVPを適用し、全版で対象patchの成功、resource／DEX再構築、署名を確認しました。
- AQUOS SH-R80P / Android 16の公式ReVanced Manager 2.6.0で246 devのpatch、resource再構築、署名まで完了しました。端末へのインストールは利用者の明示承認後に行います。

入力APK/XAPKのSHA-256と機能詳細は[v1.2.0のリリースノート](https://github.com/roflsunriz/chmate-revanced/releases/tag/v1.2.0)を参照してください。

Release assetsには`patches-1.2.1.rvp`、そのSHA-256ファイル、更新情報の`patches.json`だけを含めます。ChMate APK、XAPK、patch済みAPKは配布しません。
