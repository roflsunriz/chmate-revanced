# chmate-revanced v1.2.2

v1.2.1のAndroid版ReVanced Manager実機起動互換性を修正するリリースです。

## 修正

- ChMate 0.8.10.246 devのroot配置binary XMLで文字列poolから属性名が欠落していても、resource IDから`key`、`entries`、`defaultValue`などを復元します。
- `IntListPreference`などの必須属性を保持し、Managerで再構築・署名したAPKが起動直後に終了する問題を解消します。
- 246 devの起動・設定・板一覧に追加されたintegrity trapへ対応します。
- Compose版ChMate設定の下部に「画像掲示板の板」「高度なNGルール」を直接表示します。

## 検証

- JDK 17のJUnit、Android Lint、RVPビルドをclean状態で完了しました。
- ChMate `0.8.10.165`、`0.8.10.179`、`0.8.10.202 dev`、`0.8.10.241`、`0.8.10.244 dev`、`0.8.10.245 dev`、`0.8.10.246 dev`へ同じRVPを適用し、全版で対象patchの成功、resource／DEX再構築、署名を確認しました。
- AQUOS SH-R80P / Android 16の公式ReVanced Manager 2.6.0で246 devをデータ保持更新し、起動、ネイティブ設定、画像掲示板・高度NGの直接導線、URLからの4chan板オープン、板一覧更新を確認しました。

入力APK/XAPKのSHA-256と機能詳細は[v1.2.0のリリースノート](https://github.com/roflsunriz/chmate-revanced/releases/tag/v1.2.0)を参照してください。

Release assetsには`patches-1.2.2.rvp`、そのSHA-256ファイル、更新情報の`patches.json`だけを含めます。ChMate APK、XAPK、patch済みAPKは配布しません。
