# chmate-revanced v1.1.0

ChMateのスレッド表示と投稿に関する機能を追加し、ニコニコ動画のサムネイル対応を広げたリリースです。

## 主な変更

- 既存のNG設定と併用できる高度なNGルールを追加。文字列・数値・時間条件、AND、否定、適用する板やスレッドの指定、連鎖NG、通常／透明あぼーんに対応しました。
- 投稿間隔エラーに待機秒数が明記された場合、返信と新規スレッド作成を指定時間後に最大2回再試行します。
- 4chan、ふたば、jschan系サイトの板・スレッドをChMate内で読み込み、各サイトの投稿フォームを開けるようにしました。
- ニコニコ動画の`so`・`nm`形式にもサムネイル処理を適用し、動画情報APIを使って画像を取得します。対応動画リンクの公開メタデータをスレッド内のカードに表示し、設定で切り替えられます。
- ビルド時とAndroidテスト用の推移依存に残っていた既知脆弱性を解消しました。

詳細は[変更履歴](https://github.com/roflsunriz/chmate-revanced/blob/v1.1.0/CHANGELOG.md)を参照してください。

## 検証

- 端末: AQUOS SH-R80P / Android 16
- ChMate: `0.8.10.241`を公式ReVanced Managerでpatch・署名し、データを保持して更新インストール
- 高度NG: ローカル30レスのスレッドで本文一致と参照連鎖、通常／透明あぼーん、ルール無効化による復帰、スクロール後の他レス表示を確認
- 投稿再試行: ローカル模擬掲示板で返信と新規スレッド作成の再送、別エラーでの停止を確認
- 画像掲示板: 4chan `/po/`、ふたば料理板、jschan系 `/tech/` の一覧、スレッド、画像、投稿フォームを確認
- 動画: 公開スレッドでニコニコ動画`sm`・`so`、YouTubeのサムネイル／情報カード、展開・復帰、設定切替を確認
